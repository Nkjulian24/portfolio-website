# Elite Data Analyst Portfolio Template

A one-page, modern, dark/light portfolio website for Excel, Power BI and SQL data analysts.

## Files
- `index.html` — website structure and content sections
- `css/style.css` — all design, layout, responsive styling and brand color
- `js/data.js` — projects and case studies; easiest file to customize
- `js/main.js` — theme toggle, particle animation, modal, gallery and interactions
- `assets/images/` — image placeholders
- `docs/CUSTOMIZATION-GUIDE.md` — step-by-step guide

## Start
Open `index.html` in your browser or use VS Code Live Server.
